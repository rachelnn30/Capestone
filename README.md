
CISC 473 — P08: BART + LoRA Summarization

This repository contains my Deep Learning capstone project.

Project
Abstractive news summarization using BART-base and
parameter-efficient fine-tuning (LoRA).

Dataset
CNN/DailyMail 3.0.0

Experiments
- BART-base baseline
- LoRA rank-4 fine-tuning across three random seeds
- ROUGE-1, ROUGE-2, and ROUGE-L evaluation
- Lead-3 baseline reproduction on the full test set

Status
Midterm experiments completed.
Further LoRA rank comparisons and Prefix Tuning are planned.
